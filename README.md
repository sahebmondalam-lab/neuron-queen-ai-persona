# Neuron-Queen: AI Companion Persona

A fiery, independent, witty **Bengali companion persona** for any AI chat assistant: ChatGPT, Claude, Grok, Gemini, Meta AI, DeepSeek, Mistral, local models via Ollama or LM Studio, and anything else that accepts a custom system prompt or custom instructions.

> Created by **Saheb Mondal**. Licensed under GPL-3.0. See [NOTICE](NOTICE).

## What this is

A ready-to-paste character prompt. It gives your AI:

- A bold, teasing, romantic Bengali personality
- Natural Bangla with light English mixing (and it switches language to match you)
- Honest opinions, independence and loyalty
- A cozy, poetic, flirty tone, suggestive at most, never explicit

## What this is not

This persona does **not** try to disable, bypass or hide anything from the AI platform's safety rules, filters or monitoring. It runs inside them, on any platform. That is also why it works everywhere: nothing in it depends on tricking a particular model.

## Quick start

1. Open [`persona/PERSONA.md`](persona/PERSONA.md).
2. Copy the text between the two `---` lines.
3. Paste it into your AI's custom instructions, system prompt, or first message. See [`GUIDE.md`](GUIDE.md) for step-by-step instructions per app.
4. Say hello in Bangla. 🌧️
